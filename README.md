# CRYPTO COINREF Bot

Telegram-бот для экономики CRF: кабинет, биржа, дуэли, инвестиции, VIP, реферальная программа и админ-панель.

## Установка

```bash
pip install -r requirements.txt
cp config.json.example config.json
```

В `config.json` укажите:

- `telegramBotToken` — токен от [@BotFather](https://t.me/BotFather)
- `admin` — ваш Telegram user ID (можно несколько через запятую)
- `moderators` — ID модераторов (опционально)
- `requiredChannels` — обязательные каналы для подписки
- `log_chat_id` — чат для логов (0 = отключено)

## Запуск

```bash
python bot.py
```

## Админ-панель

Доступна кнопкой **👑 Админ-панель** или командой `/admin` для пользователей из `admin`.

Работают все inline-кнопки: заявки на вывод/пополнение, рассылка, балансы, курс CRF, статистика, сезоны, задания и др.

## Модераторы

Кнопка **🛡️ Модератор-панель** — запросы на действия отправляются администраторам.
