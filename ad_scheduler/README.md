# Планировщик рекламы для Telegram

Автопостинг в **разрешённых рекламных чатах** с интервалом **15 минут** (настраивается). Управление через Telegram-бота.

> Используйте только в чатах, где реклама разрешена правилами.

## Возможности

- **Интервал 15 минут** по умолчанию (15 / 30 / 45 / 60 / 90 / 120 мин на чат)
- **Автосинхронизация чатов** при запуске — подтягивает все группы/каналы с аккаунта
- **Несколько аккаунтов** на одном SOCKS5-прокси (для РФ)
- **SQLite БД** — аккаунты, чаты, сообщения, лог постов
- **Любые сообщения** — пересылка или прямая отправка боту (текст, фото, видео)
- **Автостарт** — запускает рассылку, если есть чаты и рекламное сообщение
- **Fallback** — если пересылка запрещена, копирует сообщение

## Установка

```bash
cd ad_scheduler
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env
python main.py
```

## Настройка `.env`

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен от @BotFather | — |
| `ADMIN_IDS` | Ваш Telegram ID | — |
| `PROXY_HOST` / `PROXY_PORT` | SOCKS5 прокси | — |
| `DEFAULT_INTERVAL_MINUTES` | Интервал постинга | `15` |
| `AUTO_SYNC_ON_START` | Синхронизация чатов при старте | `true` |
| `AUTO_START_SCHEDULER` | Автозапуск рассылки | `true` |
| `POST_DELAY_SECONDS` | Пауза между чатами | `5` |

`api_id` / `api_hash`: https://my.telegram.org

## Быстрый старт

1. Заполните `.env` и запустите `python main.py`
2. В боте: `/start`
3. **👤 Аккаунты** → добавить аккаунт (телефон + api_id + api_hash + код)
4. Чаты подтянутся **автоматически**
5. **📨 Сообщение** → отправить/переслать рекламный пост
6. Рассылка стартует **автоматически** (или нажмите **▶️ Старт**)

## Управление

| Кнопка | Действие |
|---|---|
| 📊 Статус | Состояние, лог последних постов |
| ▶️ Старт / ⏹ Стоп | Управление рассылкой |
| 📋 Чаты | Вкл/выкл чаты, интервал, тестовый пост |
| 👤 Аккаунты | Добавление и управление аккаунтами |
| 📨 Сообщение | Задать рекламный пост |
| 🔄 Синхронизация | Обновить чаты с аккаунта |
| ⚙️ Настройки | Интервал для всех чатов сразу |
