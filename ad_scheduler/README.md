# Планировщик рекламы для Telegram

Автоматическая публикация рекламных постов в **разрешённых рекламных чатах** с интервалом (по умолчанию 1 час). Управление через Telegram-бота.

> Используйте только в чатах, где реклама разрешена правилами. Автор не несёт ответственности за нарушение правил площадок.

## Возможности

- **Несколько аккаунтов** на одном SOCKS5-прокси (удобно для РФ)
- **База SQLite** — чаты, аккаунты, сообщения, история
- **Синхронизация чатов** — подтягивает группы/каналы, где уже состоите
- **Ручное добавление** — @username, ID или invite-ссылка
- **Пересылка любого сообщения** — текст, фото, видео и т.д.
- **Автозапуск** — если рассылка была включена, после перезапуска продолжит работу
- **Интервал на чат** — 1 / 2 / 3 часа

## Установка

```bash
cd ad_scheduler
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env
```

## Настройка `.env`

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_IDS` | Ваш Telegram ID (через запятую) |
| `PROXY_HOST` | SOCKS5 хост |
| `PROXY_PORT` | SOCKS5 порт |
| `PROXY_USER` / `PROXY_PASS` | Логин/пароль (если есть) |
| `DEFAULT_INTERVAL_HOURS` | Интервал по умолчанию (1) |

Получить `api_id` и `api_hash`: https://my.telegram.org

## Запуск

```bash
python main.py
```

## Быстрый старт

1. `/start` в боте управления
2. **👤 Аккаунты** → добавить аккаунт (имя, телефон, api_id, api_hash, код из SMS)
3. **🔄 Синхронизация** → подтянуть чаты из аккаунта
4. **📨 Сообщение** → переслать рекламный пост боту
5. **📋 Чаты** → включить нужные чаты
6. **▶️ Старт** → запуск рассылки

## Структура

```
ad_scheduler/
├── main.py           # точка входа
├── config.py         # настройки из .env
├── database.py       # SQLite
├── userbot.py        # Pyrogram + SOCKS5
├── scheduler.py      # планировщик постов
├── bot/
│   ├── handlers.py   # команды управления
│   └── keyboards.py
└── data/             # сессии и БД (создаётся автоматически)
```

## Важно

- Один прокси используется для всех аккаунтов — настройте в `.env`
- Новые чаты при синхронизации добавляются **включёнными**; существующие не меняют статус
- Сообщение хранится как ссылка на оригинал (пересылка), поэтому поддерживаются любые типы контента
