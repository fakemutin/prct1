## ⚡ Шпаргалка за 30 секунд

```
1. @satkavpn_bot → Подписка → оплатить
2. Скопировать ссылку ЦЕЛИКОМ
3. Happ → + → вставить → потянуть вниз (обновить)
4. Выбрать сервер → Подключить
```

**Глушилки LTE?** → секция **«Для моб. операторов»** в Happ (есть на **всех платных** тарифах).

**Не работает?** → обнови подписку → смени сервер → перезапусти Happ → напиши в [@satkavpnsupport](https://t.me/satkavpnsupport) или **«Оператор»**.
