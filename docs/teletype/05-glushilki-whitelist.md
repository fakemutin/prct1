# 📡 Глушилки и белые списки — полный гид

> Как обходить блокировки мобильного интернета (LTE) в Satka VPN.

---

## Главное за 10 секунд

★ **Обход глушилок есть на ВСЕХ платных тарифах** ★

Не нужно покупать отдельный тариф «только для глушилок».  
Открой Happ → секция **«Для моб. операторов»** → выбери сервер или **«🎲 Авто-выбор белые списки»**.

---

## Что такое глушилки и белые списки

**Глушилки** — когда мобильный оператор (МТС, Билайн, Мегафон, Tele2) режет или блокирует интернет, оставляя доступными только «белые» сайты (банки, госуслуги и т.д.).

**Белые списки (БС)** — специальные серверы Satka VPN, которые работают в таких условиях через разрешённые каналы.

---

## Где найти в Happ (платный тариф)

```
⬇️ Для моб. операторов ⬇️
   🇷🇺 Белые списки | ТОП #1
   🇷🇺 Белые списки | ТОП #2
   ...
   🎲 Авто-выбор белые списки    ← начни с этого

⬇️ Обычные локации ⬇️
   (обычные VPN-серверы для Wi‑Fi)
```

---

## Пошагово на LTE

1. Убедись, что подписка **активна** (проверь в [@satkavpn_bot](https://t.me/satkavpn_bot))
2. Открой **Happ**
3. **Потяни список вниз** — обнови подписку
4. Перейди в **«Для моб. операторов»**
5. Выбери **«🎲 Авто-выбор белые списки»**
6. Нажми **Подключить**
7. Проверь YouTube / Telegram

---

## Если не работает на LTE

| Шаг | Действие |
|-----|----------|
| 1 | Обнови подписку в Happ (потяни вниз) |
| 2 | Попробуй **другой** сервер из «Для моб. операторов» |
| 3 | Перезапусти Happ |
| 4 | Перезагрузи телефон |
| 5 | Выключи Wi‑Fi — проверь именно на LTE |
| 6 | Напиши оператора (МТС/Билайн/…) в поддержку |

---

## Тариф «Для мамы» — в чём разница?

| | Все платные | «Для мамы» |
|---|-------------|------------|
| Глушилки | ✅ полный блок | ✅ урезанный набор |
| Обычные серверы | ✅ полный каталог | ✅ 4 сервера |
| Устройств | по тарифу | 1 |
| Цена | от 50₽/мес | от 69₽/мес (но только 1 устр.) |

**«Для мамы»** — для тех, кому нужен **самый дешёвый** вариант на **один телефон** с предвыбранными серверами.  
**Не потому что только там есть глушилки.**

---

## Бесплатный тариф и глушилки

На **бесплатных 4 днях** полного блока белых списков **нет**.  
Для глушилок нужен **платный** тариф.

---

## Банковские приложения

На белых списках Satka VPN часть российских приложений (Сбер, Ozon, 2GIS и др.) идёт **напрямую**, без VPN — чтобы банки не блокировали вход. Это нормальное поведение.
