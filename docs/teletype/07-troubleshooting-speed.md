# 🐌 Медленно, таймаут, отваливается

> VPN подключился, но тормозит, рвётся или не грузит сайты.

---

## Медленная скорость

| Что сделать | Зачем |
|-------------|-------|
| Выбери **ближайший** сервер | Меньше пинг |
| Попробуй **другой** сервер в той же секции | Может быть перегруз |
| На LTE → **«Для моб. операторов»** | Обычные серверы на глушилках медленные |
| Не качай **торренты** на слабой сети | Забивает канал |
| Проверь скорость **без VPN** | Может проблема у оператора |

---

## Таймаут / не грузит сайты

1. **Обнови** подписку в Happ
2. **Смени** сервер (особенно на LTE — в секцию глушилок)
3. **Переподключись** (выкл → вкл VPN)
4. При смене Wi‑Fi ↔ LTE — **переподключи** VPN вручную

---

## Отваливается / разрывается

| Причина | Решение |
|---------|---------|
| Смена сети Wi‑Fi ↔ LTE | Переподключи VPN |
| Устаревший список серверов | Обнови подписку (потяни вниз) |
| Перегруженный сервер | Смени на другой |
| Другой VPN мешает | Выключи всё лишнее |
| Слабый сигнал LTE | Подойди к окну / смени место |

---

## YouTube / Telegram не открывается

1. VPN **подключён**? (значок в статус-баре)
2. Попробуй сервер с пометкой **YT** / **YouTube**
3. Обнови подписку
4. На iPhone — выключи **Limit IP Address Tracking** для Wi‑Fi

---

## Gateaway 502 / ошибки в Happ

1. Смени сервер — ошибка часто на конкретной ноде
2. Обнови подписку
3. Подожди 5–10 минут — может временный сбой
4. Не помогло → скрин в [@satkavpnsupport](https://t.me/satkavpnsupport)

- Какой сервер выбран (название из Happ)
- Скрин скорости / ошибки
