# ✅ Что можно и что нельзя

> Правила использования Satka VPN — чтобы подписка работала долго.

---

## ✅ Можно

| Действие | Комментарий |
|----------|-------------|
| Использовать на **своих** устройствах | В пределах лимита тарифа |
| YouTube, Telegram, соцсети, браузер | Основное назначение |
| Глушилки / белые списки на LTE | На всех платных тарифах |
| Одна ссылка на несколько **своих** устройств | 1 / 3 / 7 / 25 — по тарифу |
| Пробный период 4 дня | Один раз на аккаунт |
| Продлевать и менять тариф | В боте или кабинете |

---

## ❌ Нельзя

| Действие | Что будет |
|----------|-----------|
| **Передавать ссылку** другим людям | Блокировка HWID, подписка перестанет работать |
| **Повторно** брать бесплатные 4 дня | Система не даст |
| **Продлевать** бесплатный тариф | Только один раз |
| Использовать на **больше устройств**, чем в тарифе | Ошибка лимита устройств |
| Делиться аккаунтом с друзьями | Риск блокировки |

---

## ⚠️ Не рекомендуется

- Держать **два VPN** одновременно — конфликты
- Копировать ссылку **не полностью** — не импортируется
- Игнорировать **обновление** подписки в Happ после оплаты
- Покупать «Для мамы» только ради глушилок — они есть на **всех платных**

---

## 🔒 Конфиденциальность

- **Не публикуй** свою ссылку подписки в чатах, форумах, соцсетях
- Ссылка = доступ к твоему VPN. Кто угодно с ссылкой может использовать слоты
- При утечке → напиши **«Оператор»** для сброса

---

## 💬 Поддержка

Мы помогаем с:
- Подключением и Happ
- Тарифами и оплатой
- Ошибками и диагностикой
- Кабинетом и ботом

Мы **не** выдаём:
- Технические ключи, IP серверов, внутренние настройки
- Доступ к чужим аккаунтам
