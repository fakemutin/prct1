# 📱 Несколько устройств на одной подписке

> Сколько устройств можно, как подключить телефон + ноут + планшет.

---

## Лимиты по тарифам

| Тариф | Устройств |
|-------|-----------|
| 👤 Базовый | **1** |
| 👩 Для мамы | **1** |
| ➕ Расширенный | **3** |
| 🏠 Семейный | **7** |
| 💼 Бизнес | **25** |

---

## Как подключить несколько устройств

**Одна и та же ссылка** на все устройства:

1. [@satkavpn_bot](https://t.me/satkavpn_bot) → скопируй ссылку подписки
2. На **каждом** устройстве: Happ → **+** → вставь ссылку
3. Обнови подписку на каждом
4. Подключайся

> Не нужно покупать отдельную подписку на каждый телефон — если тариф на 3 устройства, хватит одной ссылки.

---

## Пример: Семейный тариф (7 устройств)

```
Телефон папы     → Happ → та же ссылка ✅
Телефон мамы     → Happ → та же ссылка ✅
Планшет ребёнка  → Happ → та же ссылка ✅
Ноутбук          → Happ → та же ссылка ✅
Android TV       → Happ → та же ссылка ✅
...до 7 штук
```

---

## Ошибка «лимит устройств» / HWID

Появляется, если:
- Подключилось **больше устройств**, чем в тарифе
- Кто-то ещё использует **твою ссылку**
- Старые устройства не «отвязались»

**Решение:**
1. Отключи VPN на лишних устройствах
2. Напиши [@satkavpnsupport](https://t.me/satkavpnsupport) → **«Оператор»** → попроси сброс HWID

---

## Можно ли дать ссылку другу?

**❌ Нет.** Ссылка привязана к твоему аккаунту.  
Передача другим → блокировка → перестанет работать у всех.

Для друга — пусть оформит свою подписку или используй **рефералку**.

## Телевизор и роутер

| Устройство | Как |
|------------|-----|
| **Android TV** | Установи Happ, импортируй ссылку |
| **Smart TV без Android** | Раздай VPN с телефона (точка доступа) |
| **Роутер** | Если роутер поддерживает VPN-клиент — импорт подписки (зависит от модели) |
