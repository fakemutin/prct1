## Как публиковать

1. Зайди на [teletype.in](https://teletype.in) → **Новая запись**
2. Открой нужный `.md` файл из этой папки
3. Скопируй текст **начиная с заголовка `#`** (без имени файла)
4. Вставь в Teletype — markdown подхватится автоматически
5. Добавь **обложку** (рекомендуем 1280×720, тёмный фон + логотип Satka)
6. Опубликуй
7. В главном посте (`00-NAVIGATION-HUB.md`) замени `#` в ссылках на реальные URL статей

## Оформление на Teletype (советы)

### Цветовая схема Satka
- Фон обложки: `#0d1117` или `#1a1a2e`
- Акцент: `#00d4aa` / `#4ade80` (зелёный)
- Текст на обложке: белый

### Структура каждой статьи
- **H1** — заголовок с эмодзи
- **Blockquote** (`>`) — краткое описание в начале
- **Таблицы** — для тарифов, чеклистов
- **Разделители** `---` — между крупными блоками
- **Код-блоки** — для шпаргалок

### В конце каждой статьи
Замени `← Вернуться к навигации` на ссылку на опубликованный hub-пост.
